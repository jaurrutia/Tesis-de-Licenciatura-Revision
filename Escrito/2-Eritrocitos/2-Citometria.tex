Un citómetro de flujo está compuesto por tres sistemas principales: el sistema fluídico, el sistema óptico y el sistema electrónico \cite{mckinnonFlowCytometryOverview2018}.  El sistema fluídico tiene como objetivo transportar las partículas hasta el punto de intersección con el láser mediante un estrechamiento progresivo del flujo, de modo que las partículas atraviesen el láser de forma individual y sean analizadas una a una \cite{mckinnonFlowCytometryOverview2018}. En años recientes, se han desarrollado citómetros con enfoque acústico, en los cuales ondas ultrasónicas complementan el enfoque hidrodinámico para mejorar la alineación de las células incrementar la velocidad de adquisición y reducir el riesgo de obstrucción del sistema \cite{giengerAssessmentDeformationHuman2019}. Por otra parte, el sistema óptico está formado por uno o varios láseres, lentes de colección  y detectores; los láseres iluminan las partículas que atraviesan la región de análisis, mientras que las lentes colectan la luz esparcida, que suele detectarse mediante un fotodiodo o tubos fotomultiplicadores \cite{mckinnonFlowCytometryOverview2018}. En particular, para medir el FSC se coloca una barra de bloqueo de luz para evitar el paso el haz láser directo sobre el fotodiodo y que lo sature \cite{mckinnonFlowCytometryOverview2018}. La Fig. \ref{fig:flow_cyt} muestra de manera esquemática la disposición de estos elementos, así como los tres sistemas que conforman un citómetro de flujo. Finalmente, el sistema electrónico convierte las señales ópticas registradas por los detectores en señales digitales para su posterior procesamiento \cite{mckinnonFlowCytometryOverview2018}.
